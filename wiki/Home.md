The hybrid is the product.

**Matrix** is the weather: sessions fall like code. Long. Green. Easy to drown in.

**Negentropy** is the work: pull a thread out of that rain. Name it. Fence it. Land it. Leave a handoff a human can read in one minute.

n-ai-ssance is that work as five Grok skills. No keys. No network. No suite.

---

## Wake

Agent work leaves weather.

Transcripts swell. Folders multiply. Closing a chat feels like losing the day. Starting without a written goal invites thrash. Temporary captures vanish.

You do not need another dashboard.

You need a **map**, not a dump.

---

## Five verbs

```
/session-map      identity · relay · spine · paths     (not the jsonl)
/scan-sessions    inventory of local agent folders     (no :8765)
/reconstruct      re-read a day from disk              (nothing streams)
/intent           outcome · surface · fence            (write it down)
/durable-land     copy-first stamp + MANIFEST          (originals stay)
```

These are procedures. They install into `~/.grok/skills`. They also run as scripts under `skills/*/scripts/`.

---

## Install

```bash
git clone https://github.com/theRensisioure/n-ai-ssance.git
cd n-ai-ssance
python skills/install_to_grok.py
```

Windows lands in `%USERPROFILE%\.grok\skills\`.  
macOS and Linux land in `~/.grok/skills/`.  
Override with `N_AI_SSANCE_GROK_SKILLS`.

Then type a slash. Start with `/session-map`.

Prove the pack:

```bash
python scripts/sterile-check.py
python -m pytest tests -q
```

## Palette (the hybrid)

Two channels. Both dark. Neither rave.

- **Void** — `#030605` / `#050a07`
- **Phosphor** — `#3dcc6a` body, `#5dff8a` only for a single call to action
- **Instrument cyan** — `#7cf7ff` for names that must stand out (slash commands, product nouns)
- **Muted sage** — `#5a8a6e` for asides

Monospace for verbs and paths. Short sentences for humans. No yellow fills. No neon blast. Edge grit only.
