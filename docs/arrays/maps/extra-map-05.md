## Map
- **Skill name:** reconstruct (`/reconstruct` when D3 ships)
- **What this is:** Docs-only **teaching path** for re-membering a day from disk — not resurrecting a chat process
- **Not this:** Overwrite of day boards, streaming “continue old mind,” suite board host
- **Intent spine:** Fresh instance + disk truth — work names first, indices secondary; stamped new file optional; never overwrite

- **Learner outcomes:**

  - Can list hard never-dos: overwrite, invent closed items, stream old mind
  - Separates “start fresh” courage from avoidance of reading the board
- **Ring law:** Reconstruct is a portable procedure; scanner board is optional host, not required classroom
