# Use case · Intent fence

## Situation (synthetic)

Alex opens a tool and thrash-starts: “also fix CI, and the docs, and maybe rebrand.”  
River sees three product directions in one message.  
No written goal packet on the session.

## Approach

When intent is missing, run a short **fence**:

1. **Outcome** — what exists when this is done?  
2. **Surface** — where does it live (repo, skill, doc)?  
3. **Fence** — what is explicitly out?  

Write a small packet on disk for that session. If a packet exists, summarize the spine before expanding scope.

## Benefit

- Stops dual-tracking mid-run  
- Gives agents a **loadable** goal (not a vibe)  
- Makes “no” cheaper — out-of-fence work is named  

## If skipped

Every tool call invents a new product. Cost shows up as fatigue, not a failed test.
