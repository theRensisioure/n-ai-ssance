# Author-facing Socratic series

**Audience:** the author (and agents coaching the author).  
**Not** the public README voice — see [../FOR-READERS.md](../FOR-READERS.md).

## How this series is written (response style)

Matched to how this author best responds to Socratic work:

1. **Mirror first** — restate the distinction in one sentence before the next probe.  
2. **Concrete over rankings** — story / artifact / next physical action, not 1–10 scores.  
3. **Short chunks** — one live question at a time in conversation; this *file* sequences depth across prompts so the pile is on disk, not in working memory.  
4. **Press, not oracle** — prompts sharpen; they do not replace judgment.  
5. **Seeds ≤5** when stuck — never a questionnaire wall.  
6. **Meaning-first names** — work names, not filing codes.  
7. **Park thrash** — if a pivot appears mid-series, park the old thread in one line; do not dual-run.
