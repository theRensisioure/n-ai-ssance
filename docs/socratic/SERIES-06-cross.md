# Socratic series · Cross-approach tensions

## Spine (mirror)

The five approaches **compete for attention**. Order is a product decision.

## Sequenced prompts

**P1.** If you could keep only two approaches as skills for six months, which two, and what dies?

**P2.** Map vs reconstruct: which fails first when you are exhausted?

**P3.** Intent vs scan: which prevents more wasted agent hours?

**P4.** Durable land vs all the others: is land a foundation skill or a side door?

**P5.** Where does Sesefus product work **stop** and SSFS skill work **start** so neither pretends to be the other?

## Seeds if stuck

1. Rank the five by “pain if missing tomorrow.”  
2. Draw a one-line dependency: which approach unblocks which.  
3. Name one false unification fantasy.  
4. Write the ring law in twelve words.  
5. Park monorepo.
