# Socratic series · Scan sessions

*Ground story: no suite server — use-cases/04.*

## Spine (mirror)

Finding work is **inventory**, not nostalgia for a GUI.

## Sequenced prompts

**P1.** Without a board, how do you currently choose which session to reopen—recency, pain, or title?

**P2.** What title shape would make “example-app auth” findable a week later without opening the file?

**P3.** If scan-sessions returned twenty hits, what filter would you demand first: project, agent, or age?

**P4.** Where does “I can’t find it” actually mean “I don’t want to re-enter that context”?

**P5.** What would make a pure skill scan *good enough* that you stop waiting for the suite to launch?

## Seeds if stuck

1. Invent five synthetic session titles; rank readability.  
2. Ban id-sliced titles in one sentence of policy.  
3. Name one session you lost and what the title should have been.  
4. Decide CLI list vs agent narration as primary output.  
5. Park cross-provider perfection until Grok path works.

## Done-when

You would ship scan-sessions even if the desktop suite never opens on that machine.
