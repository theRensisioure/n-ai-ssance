# Socratic series · Reconstruct from disk

*Ground story: empty morning coach — use-cases/02.*

## Spine (mirror)

Continuity is **re-membering from disk**, not resurrecting a chat process.

## Sequenced prompts

**P1.** What did you treat as the “real” day yesterday—the chat, or the board file? When they disagreed, which one lied more often?

**P2.** If reconstruct leads with queue indices instead of work names, what does that do to your body on reattach?

**P3.** What is the smallest pin (one file, one id) that stops a brand-new empty coach from feeling like amnesia?

**P4.** When is “start fresh” courage, and when is it avoidance of reading the board?

**P5.** What must reconstruct *never* do (overwrite, invent closed items, stream old mind)?

## Seeds if stuck

1. Open only active queue + active slot; stop.  
2. Write one carry-forward in work names.  
3. Name one false restart from the last month (synthetic ok).  
4. Decide: reconstruct is coach ritual or agent skill first.  
5. Park multi-day history theater.
